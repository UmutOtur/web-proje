# web-proje
İlk web sitem basit bir hastane randevu sistemi üzerine kurulmuştur.
## 💻 Kurulum ve Çalıştırma (How to Run)
Proje herhangi bir backend sunucusu (Node.js, PHP, Python vb.) veya harici SQL veritabanı bağımlılığı gerektirmediği için doğrudan tarayıcı üzerinde çalıştırılabilir:

Bu depoyu (repository) bilgisayarınıza indirin veya kopyalayın:

```bash
git clone https://github.com/UmutOtur/web-proje.git
```
Proje klasörünü VS Code veya herhangi bir editör ile açın.

index.html dosyasına sağ tıklayarak Open with Live Server seçeneğini seçin (Geliştirici ortamında sayfalar arası localStorage senkronizasyonunun kusursuz çalışması için Live Server ile açılması tavsiye edilir).

Tarayıcınızda açılan ekrandan randevu oluşturup test etmeye başlayabilirsiniz.
